# 搜索评分与独立验收

项目面向长程视频生成的持续改进；当前已实现冻结模型下的 Harness 搜索与独立晋升，模型权重训练及 Harness／权重联合晋升属于后续目标。

当前 Harness RSI 在冻结模型与评测口径下，用 GEPA 搜索五个 Agent 的系统提示词及共享经验 memory。任务按来源或完整项目隔离为四组：Train 提供反思证据，并用搜索分 S 比较父子候选；Validation 默认按平均 S 选择 best；Promotion 在独立任务上配对复评 base 与 best，结合报告分 R、有效性及回退约束决定是否晋升；Test 仅报告留出任务上的质量差异，不参与搜索或晋升。S 的提升不保证 R 的提升，也不保证候选能够晋升。
